# Earth Textures

Para visualização premium da Terra em 3D, faça o download das texturas em alta resolução.

## Instruções de Download:

1. Faça o download da textura do dia em 2K (por exemplo, `earth_day_2k.jpg` do repositório Solar System Scope ou outro banco de dados público).
2. Salve o arquivo nesta pasta com o nome exato:
   `earth_day_2k.jpg`

## Links Úteis:
- [Solar System Scope Textures](https://www.solarsystemscope.com/textures/)
- [NASA Earth Observatory](https://earthobservatory.nasa.gov/)

*Se a textura não estiver presente, a aplicação usará um modelo de fallback estilizado azul escuro automaticamente.*
